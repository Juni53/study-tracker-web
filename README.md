# Study Tracker(Web 版)

勉強時間を記録して、ポイントをためながら、試験に向けた進み具合を管理するアプリです。
ブラウザだけで動き、インストールも(任意で)できます。**記録は、使っている端末の中にだけ保存され、外部のサーバーへは送られません。**

**サイト: https://juni53.github.io/study-tracker-web/**

## できること

- **ホーム**: 連続記録、今日・今月の目標の進み具合、近い試験、1週間のグラフ。
- **ストップウォッチ**: 勉強の時間を計って記録。ポモドーロタイマーも使えます。
- **記録ログ**: これまでの記録の一覧。手動での追加、タグでの絞り込み。
- **カレンダー**: 勉強した日を、色の濃さで表示。
- **試験管理**: 試験の日付と目標の勉強時間を登録して、進み具合を確認。
- **統計**: 今週・今月・全期間の勉強時間、曜日別、タグ別、充実度。
- **ショップ**: ためたポイントを、自分で決めたごほうびと交換。「さぼり券」で連続記録を守れます。
- **設定**: 目標、タグ、バックアップ、ポイントの計算など。

初めて開くと、各タブの使い方を紹介する「はじめに」が出ます(設定の「このアプリについて」から、いつでも見直せます)。

## 使い方

1. 上のサイトを、Chrome か Edge で開きます(Windows・Chromebook が主な対象です。iPad の Safari でも動く想定ですが、確認は限られています)。
2. アドレスバーのインストールのアイコン(または、設定の「アプリとしてインストール」)で、アプリとして使えます。iPad は、共有ボタンから「ホーム画面に追加」です。インストールすると、オフラインでも使えます。

## データについて(大事です)

- 記録・ポイント・設定は、**いま使っているブラウザの中にだけ**保存されます。別の端末・別のブラウザとは共有されません。ブラウザの「サイトデータ」を削除すると、記録も消えます。
- **定期的に、設定 → データ管理 →「バックアップを保存」で、バックアップを取ってください。** 取りどきは、リマインダーが知らせます。
- 端末を移るときは、古い端末でバックアップを保存し、新しい端末で「バックアップから復元」します。
- Python のデスクトップ版を使っていた場合は、そのデータも取り込めます(手順は [README_web.md](README_web.md) の「デスクトップ版のデータを取り込む」)。

## プライバシー

- 記録や設定は、外部のサーバーへ送られません。すべて、端末の中で処理されます。
- アプリの新しい版を確認するために、このサイトへ接続することはあります(記録は含まれません)。
- 「フィードバック」タブがある場合は、そのリンクを開いたときだけ、フォームのページ(外部のサービス)へ移動します。

## 開発する人へ

- 仕組み・進み具合・テスト・公開の手順は、[README_web.md](README_web.md) にあります。
- 動かすには `npm ci`、試すには `npm test`(Node.js が必要)。公開されるのは `ui/` フォルダの中身です。
